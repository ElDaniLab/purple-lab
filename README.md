# purple-lab

A public record of the cybersecurity things I build and test: a home lab, attack and defense exercises, networking labs, and notes on practice platforms. Each exercise is written up so a newcomer can reproduce it. Made for learners and anyone curious how I work.

## How to use this repo

Start with the lab overview, then pick an exercise from the index. Each exercise is self-contained.

## Lab overview

All exercises run in a small isolated virtual lab (an attacker VM and a target VM on a network with or without internet access). See [lab-setup](lab-setup/) for the architecture and build guides.
